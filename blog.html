📜 Article 1: Single-Stack vs Dual-Stack History Architectures

Published by Computer Science Dept • 5 min read

Modern web browsers like Chrome, Firefox, and Safari actually maintain two distinct stacks to support full back-and-forward navigation:

  • Back Stack: Stores visited pages in LIFO order. When you click a link, the target URL is pushed to the Back Stack.
  • Forward Stack: Holds pages popped from the Back Stack when you click the Back button.
  • Branching Rule: If you navigate to a new URL after going back, the Forward Stack is completely wiped!
// Dual Stack Architecture Simulation function visitNewPage(url) { backStack.push(url); forwardStack.clear(); // Wipes forward history upon branching navigation }

⚡ Article 2: How the V8 Engine Manages the JavaScript Call Stack

Published by System Architecture Group • 7 min read

The JavaScript runtime is single-threaded and contains a execution stack called the Call Stack. Every function call creates a stack frame containing primitive local variables, arguments, and return address pointers.

Understanding Stack Overflow: If a recursive function fails to hit its base case, stack frames keep pushing until memory limit is exceeded, triggering RangeError: Maximum call stack size exceeded.
