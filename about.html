ℹ️ About PageStack Engine

Algorithm Complexity, Data Structure Architecture & Memory Model

🧠 Data Structure Architecture

The PageStack class is an array-backed stack data structure. It enforces abstract data type boundaries by only exposing defined operations: push(), pop(), peek(), isEmpty(), and display().

class PageStack { constructor() { this.items = this.loadFromLocalStorage() || []; } push(page) { this.items.push(page); // O(1) Amortized this.saveToLocalStorage(); } pop() { if (this.isEmpty()) return null; const popped = this.items.pop(); // O(1) this.saveToLocalStorage(); return popped; } peek() { return this.items[this.items.length - 1]; // O(1) } }

📊 Time & Space Complexity Analysis

Because insertion and deletion occur exclusively at the end of the underlying array, all core stack operations execute in constant time $O(1)$.

Operation Method Time Complexity Space Complexity Description
Push push(page) O(1) O(1) Appends element to top of stack
Pop pop() O(1) O(1) Removes top element from stack
Peek peek() O(1) O(1) Returns top element without removal
Is Empty isEmpty() O(1) O(1) Checks if stack length equals zero
Full Stack display() O(N) O(N) Iterates through all N historical pages
