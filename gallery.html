📊 PUSH & POP Operation Diagrams

Visualizing how pointer modifications occur at runtime when navigating forward or backward.

1. PUSH Operation Flow (Forward Navigation)

[ Initial Stack ]   →   top → [ Services ] → [ About ] → [ Home ]
[ User Clicks Gallery ] →  PUSH("Gallery")
[ Updated Stack ]   →   top → [ Gallery ] (NEW TOP) → [ Services ] → [ About ] → [ Home ]

2. POP Operation Flow (Back Button)

[ Current Stack ]   →   top → [ Gallery ] → [ Services ] → [ About ] → [ Home ]
[ User Clicks Back ] →  POP() → Returns "Gallery"
[ New Top Peek ]   →   top → [ Services ] (NEW TOP) → [ About ] → [ Home ]
[ Action ]          →   Navigate browser to window.location.href = "services.html"
