⚙️ How the Stack Works

A Stack is a linear data structure that follows a strict Last In, First Out (LIFO) order. Elements are inserted and removed from the exact same end, known as the TOP of the stack.

📥
New Page → PUSH
Visiting a new page pushes a node onto the top of the stack.
📤
Back Button → POP
Popping removes the current top element and exposes the previous page.
👁️
Top Element → PEEK
The element at the top of the stack always represents the active page.
⚡
Principle → LIFO
Last In, First Out property guarantees reverse-chronological order.
